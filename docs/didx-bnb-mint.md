# dIDX 一笔 BNB 铸造接口

BSC 主网，chain ID 56。默认四币篮子的退款入口：`0xc1359a0eDbdB727cd2686498be7A7403959C7C27`；dIDX：`0x5C36146A69abFd68346d801AfB911B97C18eb4b5`。

用户仅需准备 BNB 和网络 Gas，无需预先购买或授权四种成分币。网站获取逐段报价后，钱包发送一次交易：

```solidity
function mintFromBnb(
    uint256[4] calldata budgets,
    uint256[] calldata limits,
    uint256 minShares,
    uint16 maxSurplusBps,
    address meme,
    uint256 minMemeOut,
    address receiver,
    uint256 deadline
) external payable returns (
    uint256 shares,
    uint256 memeOut,
    uint256[] memory legs,
    uint256[4] memory tokenRefunds,
    uint256 bnbRefund
);
```

- `budgets` 按篮子 `assets()` 顺序指定四项 BNB 购买预算，每项大于零，总和不超过 `msg.value`。
- `limits` 按底层购买入口的固定路径指定每段最低到账；数量须等于 `legCount()`。报价与模拟使用同一链上区块，不应将最低到账设为零来绕过滑点保护。
- `minShares` 为最低 dIDX 到账。为兼容原入口保留 `maxSurplusBps` 参数，网站传 `0`；合约允许该参数不超过 `1000`，但实际存入始终使用零超额容忍，不会因传入更大值而留下多余代币。
- 仅铸造时 `meme` 为零地址、`minMemeOut` 为 `0`；也支持填入已发射的 meme 地址继续买入该 meme，届时必须设置其最低到账。
- `receiver` 接收 dIDX 或最终购买的 meme；多余 BNB、未用于铸造的四种代币退给付款方 `msg.sender`，即使付款方与收款方不同。
- `deadline` 为秒级 Unix 截止时间。失效、购买失败、最低到账不足或退款失败都会回滚整笔交易。

入口先按实际收到的四币数量计算可铸份额，再按当前储备比例向上取整计算所需存入量。仅存入这部分资产，多余成分币原样退款，不会再次兑换为 BNB。返回值与 `Refunded(address indexed payer, uint256 bnb, uint256[4] tokenNetAmounts)` 事件报告退款净额；模拟结果是报价，最终以实际交易回执为准。

当前默认四币已通过 BSC 分叉购买、铸造、退款及赎回联调。如果未来成分币对向篮子转账另行扣税，使实际存入无法满足精确比例，本入口会回滚；不会将超额部分静默留在储备中。篮子页折叠的直接存入入口沿用原 `DidxBasket.deposit` 的规则。

创建普通 meme 的手续费为 **0.005 BNB / 次**，由发射台收取，另付网络 Gas。这不是 dIDX 铸造费。BNB 铸造仍会产生底层兑换费用及成分币自身可能收取的交易税。

平台币 MDAQ 尚需由已配置 dev 发行并通过链上校验；含 MDAQ 的组合须分别完成篮子、报价与退款入口部署及登记后开放，不能复用本地址代表其他组合。

## 网站赎回操作

篮子页将操作分为「铸造 dIDX」「换回 BNB」「取回四种代币」。25%、50% 和「全部」只使用当前钱包在当前组合中的精确余额，不使用组合总供应量。

换回 BNB 时，如果授权额度不足，页面先明确申请本次数量的 dIDX 授权；授权本身不会卖出资产。确认授权后，网站模拟整笔赎回与兑换，显示预计 BNB 和自动计算的最低到账。用户审核报价后，再单独确认兑换交易。直接取回四种代币不需要给 Gateway 授权。

报价有效期为 60 秒。交易发送前重新模拟，并保留用户先前接受的最低到账限制；价格超出该限制时要求重新报价。页面分别显示获取报价、钱包确认、链上确认和余额同步阶段。已提交交易的哈希保存在当前浏览器，刷新页面后继续查询；读到交易所在区块或更高区块的余额后，才显示同步完成。

页面参考净值按当前链上储备和部署时绑定的 DEX 池现货价格计算，美元换算仍经过价格源有效性校验。现货读数不可用时，若发射定价用的均价源仍有效，会明确标注使用均价参考。展示净值不作为交易最低到账或新发射定价依据；兑换金额由实际交易模拟决定，发射仍使用合约原有均价检查。
